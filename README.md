# 🤟 LESCOnect

**LESCOnect** es una aplicación móvil de comunicación inclusiva orientada a la interpretación, traducción y facilitación de trámites para personas sordas y con discapacidad auditiva en Costa Rica, utilizando el Lenguaje de Señas Costarricense (LESCO).

## 📐 Stack Tecnológico

- **Framework Móvil**: Expo `~57.0.18` (React Native `0.86.3` / React `19.2.3`)
- **Lenguaje**: TypeScript `~6.0.3`
- **Navegación**: Expo Router v4 (`app/`)
- **Estado de Sesión**: Zustand + MMKV
- **Peticiones y Caché de Servidor**: TanStack Query
